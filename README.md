# DriveForge

> 🚧 **Work in progress** — code coming soon.

**Multi-Modal Synthetic Data Generation for Autonomous Driving**

Safety-critical driving scenarios are rare in real-world datasets. DriveForge is a multi-modal synthetic data generation pipeline for autonomous driving that uses synchronized vehicle telemetry to generate and reason over rare driving events.

## Planned features
- Synthetic generation of rare / safety-critical driving events from synchronized vehicle telemetry
- Scenario generation and reasoning with **DriveLM**, **NVIDIA Cosmos**, and **Cosmos-Diffuse**
- Evaluation of temporal consistency, sample diversity, and downstream driving-event classification performance

## Tech stack
DriveLM · NVIDIA Cosmos · Cosmos-Diffuse · Python
